# MADRASAT IBNUHAJAR - Backend Setup Guide\n\nThis guide covers setting up the app with either **Supabase** or **Firebase** for live authentication and data persistence.\n\n## Quick Start\n\nThe app supports two backend options:\n1. **Supabase** (PostgreSQL-based, recommended for quick setup)\n2. **Firebase** (Google's Firebase, better for real-time features)\n\n---\n\n## Option 1: Supabase Setup (Recommended)\n\n### Step 1: Create a Supabase Project\n\n1. Go to [supabase.com](https://supabase.com)\n2. Sign up and create a new organization\n3. Create a new project:\n   - Project name: `madrasat-ibnuhajar`\n   - Database password: Save securely\n   - Region: Choose closest to your users\n4. Click \"Create new project\" and wait for setup (2-3 minutes)\n\n### Step 2: Set Up Database Schema\n\n1. In Supabase dashboard, go to **SQL Editor**\n2. Click \"New Query\"\n3. Copy the entire content from `db/supabase-schema.sql`\n4. Paste into the SQL editor\n5. Click \"Run\" to create all tables and policies\n\n### Step 3: Get Your Credentials\n\n1. Go to **Settings** → **API**\n2. Copy:\n   - **Project URL** (under \"Your URL\")\n   - **Anon Key** (under \"Project API keys\")\n\n### Step 4: Configure Environment Variables\n\n1. Copy `.env.example` to `.env.local`:\n   ```bash\n   cp .env.example .env.local\n   ```\n\n2. Edit `.env.local` and add:\n   ```\n   SUPABASE_URL=https://your-project.supabase.co\n   SUPABASE_ANON_KEY=your_anon_key_here\n   REACT_APP_BACKEND=supabase\n   ```\n\n### Step 5: Run the Application\n\n```bash\nnpm install\nnpm run dev\n```\n\nThe app should now connect to your Supabase project.\n\n---\n\n## Option 2: Firebase Setup\n\n### Step 1: Create a Firebase Project\n\n1. Go to [firebase.google.com](https://firebase.google.com)\n2. Click \"Get Started\"\n3. Create a new project:\n   - Project name: `madrasat-ibnuhajar`\n   - Accept default settings\n   - Click \"Create project\"\n4. Enable Google Analytics (optional)\n\n### Step 2: Set Up Authentication\n\n1. In Firebase console, go to **Build** → **Authentication**\n2. Click \"Get started\"\n3. Enable **Email/Password** provider:\n   - Click \"Email/Password\"\n   - Toggle \"Enable\"\n   - Save\n\n### Step 3: Set Up Firestore Database\n\n1. Go to **Build** → **Firestore Database**\n2. Click \"Create Database\"\n3. Choose:\n   - Location: closest to your users\n   - Security rules: \"Start in test mode\" (change later)\n4. Click \"Create\"\n\n### Step 4: Create Firestore Collections\n\nFirestore will auto-create collections when you insert data, but you can pre-create them:\n\n1. In Firestore console, click \"+ Start collection\"\n2. Create these collections:\n   - `users`\n   - `subjects`\n   - `exams`\n   - `results`\n   - `announcements`\n   - `chats`\n\n### Step 5: Get Your Credentials\n\n1. Go to **Project Settings** (gear icon)\n2. Go to **Service Accounts** tab\n3. Click \"Generate new private key\" for backend use\n4. For frontend, go to **General** tab\n5. Scroll to \"Your apps\" section\n6. Click \"</>\" (Web)\n7. Copy the Firebase configuration object\n\n### Step 6: Configure Environment Variables\n\n1. Copy `.env.example` to `.env.local`:\n   ```bash\n   cp .env.example .env.local\n   ```\n\n2. Edit `.env.local` and add your Firebase credentials:\n   ```\n   FIREBASE_API_KEY=your_api_key\n   FIREBASE_AUTH_DOMAIN=your_project.firebaseapp.com\n   FIREBASE_PROJECT_ID=your_project_id\n   FIREBASE_STORAGE_BUCKET=your_project.appspot.com\n   FIREBASE_MESSAGING_SENDER_ID=your_sender_id\n   FIREBASE_APP_ID=your_app_id\n   REACT_APP_BACKEND=firebase\n   ```\n\n### Step 7: Set Up Firestore Security Rules\n\n1. Go to **Firestore Database** → **Rules**\n2. Replace with this security ruleset:\n\n```rules\nrules_version = '2';\nservice cloud.firestore {\n  match /databases/{database}/documents {\n    match /users/{userId} {\n      allow read: if request.auth.uid == userId || request.auth != null;\n      allow write: if request.auth.uid == userId;\n    }\n    \n    match /subjects/{subjectId} {\n      allow read: if request.auth != null;\n      allow create, update, delete: if request.auth.uid == resource.data.teacher_id;\n    }\n    \n    match /exams/{examId} {\n      allow read: if request.auth != null;\n      allow create, update, delete: if request.auth.uid == resource.data.teacher_id;\n    }\n    \n    match /results/{resultId} {\n      allow read: if request.auth != null;\n      allow create, update, delete: if request.auth.uid == resource.data.teacher_id;\n    }\n    \n    match /announcements/{announcementId} {\n      allow read: if request.auth != null;\n      allow create, update, delete: if request.auth.uid == resource.data.author_id;\n    }\n    \n    match /chats/{chatId} {\n      allow read: if request.auth != null;\n      allow create: if request.auth.uid == request.resource.data.sender_id;\n    }\n  }\n}\n```\n\n3. Click \"Publish\"\n\n### Step 8: Run the Application\n\n```bash\nnpm install\nnpm run dev\n```\n\nThe app should now connect to your Firebase project.\n\n---\n\n## Switching Backends\n\nTo switch from Supabase to Firebase (or vice versa):\n\n1. Edit `.env.local`\n2. Change `REACT_APP_BACKEND` to either `supabase` or `firebase`\n3. Ensure the appropriate credentials are set\n4. Restart the app: `npm run dev`\n\n---\n\n## Default Test Accounts\n\nWhen using the in-app signup, create accounts with:\n\n**Teacher Account:**\n- Email: `ahmed@madrasat.edu`\n- Password: `teach123`\n- Name: `Teacher Ahmed`\n- Role: `Teacher`\n\n**Parent Account:**\n- Email: `omar@familymail.com`\n- Password: `parent123`\n- Name: `Parent - Update `.env.local` with production credentials\n2. Enable RLS on all tables (already configured in schema)\n3. Set up authentication email templates in Supabase\n4. Deploy to Vercel/Netlify:\n   ```bash\n   npm run build\n   ```\n\n### For Firebase:\n\n1. Update `.env.local` with production credentials\n2. Update Firebase security rules for production\n3. Configure custom domain for auth\n4. Deploy to Firebase Hosting:\n   ```bash\n   firebase login\n   firebase init\n   npm run build\n   firebase deploy\n   ```\n\n---\n\n## Next Steps\n\n1. ✅ Choose and set up your backend (Supabase or Firebase)\n2. ✅ Configure environment variables\n3. ✅ Create test accounts\n4. ✅ Test all CRUD operations\n5.
